# 实验报告截图操作指南（共 8 张）

**保存目录**（固定）：`docs/screenshots/`  
**命名规则**：必须与下表「文件名」完全一致（导出 PDF 时图片才能显示）。

---

## 截图前准备（5 分钟）

1. 启动基础设施：`docker compose -f docker-compose.core.yml up -d`
2. 启动三个 Java 服务：`powershell -File scripts\start-java-services.ps1`
3. 启动前端：`cd frontend && npm run dev` → 打开 http://127.0.0.1:9945/
4. 在系统里 **至少提 1 个问题、写 1 个回答**，并 **展开问题 2～3 次**（让浏览量、Redis 榜有数据）

**Windows 截图**：`Win + Shift + S` 选区域 → 画图/微信粘贴 → 另存为 PNG。
