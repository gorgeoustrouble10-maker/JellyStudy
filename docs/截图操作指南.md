## 1）截图前准备（按顺序做）

### 第 1 步：启动基础设施

```powershell
docker compose -f docker-compose.core.yml up -d
```

### 第 2 步：启动 Java 服务

```powershell
powershell -File scripts\start-java-services.ps1
```

### 第 3 步：启动前端

```powershell
cd frontend
npm run dev
```

浏览器打开：`http://127.0.0.1:9945/`

### 第 4 步：先造一点业务数据（很重要）

1. 进入前端问题页，至少浏览/展开问题 2~3 次。
2. 至少提交 1 个回答（后面 SkyWalking MQ Trace 要用）。
3. 打开评估页，确保有评估记录。
4. 若成长教练页无数据，先登录后点击「同步知识点库」。

### 第 5 步：一键验证环境（推荐）

```powershell
powershell -File scripts\verify-z12-demo.ps1
```

## 2）Windows 截图通用动作

1. `Win + Shift + S` 截取区域。

## 3）基础截图（10 张）逐张教程

## 图 1：`01-nacos-services.png`（Nacos 服务注册）

- 打开：`http://127.0.0.1:8848/nacos`（`nacos/nacos`）
- 点击：`服务管理 -> 服务列表`，命名空间选 `public`
- 画面必须有：`jellystudy-knowledge-provider`、`jellystudy-qa-provider`、`jellystudy-evaluate-provider`
- 保存：`docs/screenshots/01-nacos-services.png`

## 图 2：`02-question-hot-viewed.png`（前端热门/常看）

- 打开：`http://127.0.0.1:9945/#question`
- 操作：先点「热门」再点「常看」
- 画面必须有：筛选按钮（全部/热门/常看）+ 列表中的浏览数字
- 保存：`docs/screenshots/02-question-hot-viewed.png`

## 图 3：`03-evaluate-qianwen.png`（智能评估）

- 打开：`http://127.0.0.1:9945/#evaluation`
- 操作：找一条有完整评估详情的记录
- 画面必须有：题目、难度标签、评估文字、知识点标签
- 保存：`docs/screenshots/03-evaluate-qianwen.png`

## 图 4：`04-redis-hot-zset.png`（热门榜 ZSET）

执行：

```powershell
docker exec jellystudy-redis redis-cli -a jellystudy_redis ZREVRANGE jelly:hot:questions 0 5 WITHSCORES
```

- 画面必须有：命令本身 + 输出中的 `questionId` 和 `score`
- 保存：`docs/screenshots/04-redis-hot-zset.png`

## 图 5：`05-redis-view-zset.png`（常看榜 ZSET）

执行：

```powershell
docker exec jellystudy-redis redis-cli -a jellystudy_redis ZREVRANGE jelly:view:rank 0 5 WITHSCORES
```

- 画面必须有：命令 + 分数输出
- 保存：`docs/screenshots/05-redis-view-zset.png`

## 图 6：`06-skywalking-services.png`（SkyWalking 服务面板）

- 前置：运行过 `start-skywalking.bat`，且 Java 用带 Agent 方式启动
- 打开：`http://127.0.0.1:8090/`
- 操作：前端做几次提问/评估后，等待约 1 分钟
- 进入：`General Service -> Service`
- 画面必须有：`jellystudy-qa`、`jellystudy-knowledge`、`jellystudy-evaluate`（最好还能看到 Load/Latency）
- 保存：`docs/screenshots/06-skywalking-services.png`

## 图 6-补充：`06-skywalking-trace-evaluate.png`（评估 Trace）

- 打开：`http://127.0.0.1:8090/` 顶部 `Trace`
- 在左侧列表找：`evaluateQuestion` 且耗时约 2s 的记录
- 不要选：`GET:/api/health` 这种几毫秒请求
- 画面必须有：Dubbo 长耗时 + MySQL + Redis 写入相关 span
- 保存：`docs/screenshots/06-skywalking-trace-evaluate.png`

## 图 7：`07-frontend-health.png`（前端探活）

- 打开：`http://127.0.0.1:9945/` 任意页面
- 画面必须有：左侧「服务状态」+ 多个服务绿点（知识点/问答/评估，若有 coach 一并显示更好）
- 保存：`docs/screenshots/07-frontend-health.png`

## 图 8：`08-db-evaluation.png`（评估库与表）

- 工具：DBeaver
- 连接：`127.0.0.1:3307`，用户名 `root`，密码 `123456`
- 展开库：`jellystudy_evaluate`
- 画面必须有：`question_evaluation`、`answer_evaluation` 两表（最好带行数）
- 保存：`docs/screenshots/08-db-evaluation.png`

## 图 8-补充：`08-db-evaluation-schema.png`（表结构）

- 在 DBeaver 中选中：`question_evaluation`

- 画面必须有：字段名、类型等结构信息
- 保存：`docs/screenshots/08-db-evaluation-schema.png`

## 图 Z12-7：`z12-nacos-refresh.png`（Nacos 热更新，必拍）

这是作业里的重点图，必须按下面做：

1. 打开 Nacos：`http://127.0.0.1:8848/nacos`
2. 进入 `配置管理 -> 配置列表`，编辑 `jellystudy-qa.yaml`
3. 把 `recent-window-days: 7` 改成 `14`，点击「发布」
4. 新开标签页访问：`http://127.0.0.1:8082/api/questions/config`
5. 确认 JSON 出现 `"recentWindowDays": 14`（无需重启服务）
6. 截图时同一张图里同时包含：
   - Nacos 已改成 14 的配置
   - 接口 JSON 的 `recentWindowDays: 14`
7. 保存：`docs/screenshots/z12-nacos-refresh.png`

> 温馨提示：截图完成后可把 `recent-window-days` 改回 7，避免影响后续排行榜口径。

## 图 Z12-8：`z12-health-components.png`（深度健康检查）

## 图 Z12-9：`z12-skywalking-mq-coach.png`（MQ -> Coach Trace）

1. 在前端回答题目并触发评估（保证会产生评估完成事件）

3. 打开 SkyWalking：`http://127.0.0.1:8090/` -> `Trace`
4. 找包含 Coach 消费链路的 Trace（关键词通常与 `coach`、评估完成后处理相关）
5. 画面尽量包含：Evaluate 侧请求 -> RabbitMQ 相关 span -> Coach 侧处理 span（如更新学情/存储）
6. 保存：`docs/screenshots/z12-skywalking-mq-coach.png`

## 7）常见问题（拍图当天最容易踩坑）

1. **Nacos 热更新不生效**：确认改的是 `jellystudy-qa.yaml`，且点了「发布」，再刷新 `/api/questions/config`。
2. **8085 访问不到**：说明 evaluate-2 没起来，先检查双实例是否启动。
3. **SkyWalking 没数据**：先有真实请求，再等 30~60 秒刷新。
4. **排行榜没分数**：先去前端多浏览问题并提交回答，再拍 Redis 图。
5. **Word 里图片不显示**：先检查文件名和路径是否与报告引用完全一致。
