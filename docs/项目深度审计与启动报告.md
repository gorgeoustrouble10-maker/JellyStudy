1. **端到端闭环**：提问/回答 → Dubbo 异步评估 → 双库持久化 → 前端展示 → Trace 可证。

3. **降级可演示**：无 Key 时 Mock；有 Key 时 Trace ~2s 可见千问链路。
4. **文档与截图**：实验报告、时序图 PNG、10 张截图、答辩 FAQ 级说明。
5. **工程延伸**：Gateway、Testcontainers、GitHub Actions CI、打包脚本。
6. **前端体验**：单站多 Tab、Hash 路由、三服务 health 探活。

## 五、缺点与风险（诚实列项）

| 优先级 | 问题 | 影响 |
|--------|------|------|
| 高 | `local-secrets.bat` 含真实 Key（gitignore） | 泄露需轮换 DashScope |
| 高 | 自动化测试少（Redis 集成测依赖 Docker） | 回归风险 |
| 中 | 评估异步失败仅 log，用户无感知 | 体验/可靠性 |
| 中 | 配置未完全迁 Nacos 配置中心 | 多实例运维不便 |
| 中 | Gateway 路由写死 127.0.0.1 | 上云需改 lb:// |
| 低 | README 曾滞后（已更新） | 新人上手 |
| 低 | IDE 485 误报（Lombok） | 不影响运行 |

### 一键启动命令（下次自用）

```bat
:: 1. 基础设施（若未启动）
docker compose -f docker-compose.core.yml up -d

:: 2. 四个 Java 服务（含 Gateway）
powershell -File scripts\start-java-services.ps1

:: 3. 前端（在项目 frontend 目录）
cd frontend
npm install
npx vite --host 127.0.0.1 --port 9945
```

**注意：** Java 服务启动后约 **30～60 秒** 才全部就绪；Gateway 会先起来，8082 未就绪时 `/api/questions/hot` 可能 502。
