## 粘贴步骤（约 30 分钟）

1. 打开 `实验报告-第十二周-Z12.md`（Typora / VS Code / 浏览器预览均可）。
2. 新建 Word：`32308117_吕宇轩.docx`，按模板填封面（学号、姓名、课程号）。
3. **逐章复制**：从「一」到「七」，每章粘贴后检查标题格式（Word 标题 1/2/3）。
4. **第四节**：把 md 里的架构 ASCII 图换成 Word 插入 → 形状，或保留等宽字体文本框。
5. **第六节**：在「6.2 运行效果截图」各图号位置：
   - Word：插入 → 图片 → 选 `docs/screenshots/xxx.png`
   - 图题写：图 6-1 evaluate-1 instance-info …
6. **表格**：md 表格粘贴到 Word 后，用「表格工具 → 设计」统一边框。
7. 保存为 **`32308117_吕宇轩.docx`**。

## 热更新截图（图 6-7）怎么拍？

**这张图画的是啥？**  
证明 Nacos **改配置不用重启服务**。

**操作（5 分钟）**：

1. 打开 http://127.0.0.1:8848/nacos → 配置管理 → `jellystudy-qa.yaml`
2. 把 `recent-window-days: 7` 改成 `14` → 点**发布**
3. 浏览器新开 http://127.0.0.1:8082/api/questions/config
4. 看到 `"recentWindowDays": 14`（原来是 7）
5. **Win+Shift+S** 截「左 Nacos 配置 + 右浏览器 JSON」→ 存 `docs/screenshots/z12-nacos-refresh.png`
6. Word 第六节插入该图，图题：**图 6-7 Nacos 配置热更新验证**

**报告里怎么写一句话？**  
> 在 Nacos 控制台将 QA 服务的 `recent-window-days` 从 7 修改为 14 并发布后，无需重启 QA 服务，通过 `/api/questions/config` 接口即可读到更新后的值，说明 `@RefreshScope` 与 Nacos 动态配置生效。

## 常见错误

| 问题 | 处理 |
|------|------|
| Word 里图片显示破图 | PNG 必须在 `docs/screenshots/`，插入时用绝对路径浏览选中 |
| 章节对不上 | 只认「一～七」大标题，附录不用写进模板 |
| 原理和设计混在一起 | 原理放**三**，设计图放**四**，代码/数据结构放**五** |
