## 三、核心代码审计（摘要）

### 场景 1 — 热门榜

- **API**：`GET /api/questions/hot` → `QuestionServiceImpl.getHotQuestions()` → `QuestionRedisService.getHotTop()`
- **定义**：点赞×3 + 回答×2 + 浏览×0.1，7 天窗口 + 时间衰减（`QuestionRankScoring`）
- **更新**：创建/点赞/回答/浏览时 `upsertRankings`；定时 `rebuildRankings`

### 场景 2 — 常看榜 + 降库压

- **API**：`GET /api/questions/recommended` → `getMostViewedTop()`
- **浏览量**：`GET /api/questions/{id}` → DB `incrementViewCount` → `onQuestionViewed`
- **详情缓存**：`jelly:question:{id}` STRING，TTL 30min（`application.yml`）
- **同步**：写穿 + 启动预热 + 每 5 分钟全量同步（满足「缓存/数据内容同步策略」）

### 场景 3 — 评估读缓存

- **类**：`EvaluationRedisCache` + `EvaluationController` / `EvaluateServiceImpl`
- **读**：先 Redis，未命中查 `jellystudy_evaluate` 再 SET
- **写/失效**：评估完成后 `put*`；删除时 `invalidate*`
- **截图佐证**：`06-skywalking-trace-evaluate.png` 可见 Redis SETEX（可选补一张 `redis-cli GET jelly:eval:question:...`）
